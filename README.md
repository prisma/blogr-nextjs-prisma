# Fullstack Blog Example with Next.js, Prisma, Sign in with Vercel, and Neon

This is the final version of the project built in the fullstack tutorial with Next.js, Prisma, Sign in with Vercel, and Neon Postgres.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/prisma/blogr-nextjs-prisma/tree/final&env=DATABASE_URL,DATABASE_URL_UNPOOLED,NEXT_PUBLIC_VERCEL_APP_CLIENT_ID,VERCEL_APP_CLIENT_SECRET)

Use a Vercel Marketplace Postgres provider, such as [Neon](https://vercel.com/marketplace/neon), for this example. The app expects `DATABASE_URL` for pooled runtime connections and `DATABASE_URL_UNPOOLED` for Prisma schema changes.
